# ACC-C1 Brief: Remove the starter kit

## Goal

Remove the Laravel starter kit (Fortify, Livewire and Flux UI, passkeys) from getnow-auth2 so the project is the API-only Accounts module that ARCHITECTURE.md section 1 describes, before ACC-U1 builds on it. Server-side code, routes, views, config, packages and the starter-kit tests go. The token stream, the arch tests, migrations and the frontend toolchain stay. No new features. One regression test is added, because deleting the starter kit also deletes the `login` route that Laravel redirects unauthenticated requests to.

## Decisions made (do not re-decide)

1. Remove the starter kit instead of keeping it inert. Reasons: section 1 puts UI, email verification, password reset and 2FA out of scope; its web routes may be a second login and registration path outside AuthService (to be confirmed by the full route list); nothing from the starter kit merges into the main repo.
2. Server-side only. The frontend toolchain is untouched. resources/css/app.css may import Flux or Livewire assets from vendor, so `npm run build` may fail afterwards. Accepted, recorded in the ADR, because nothing here merges.
3. No migration, factory or seeder changes. Starter tables (sessions, password reset tokens, any passkey table) and the two-factor columns stay (DBS3). `php artisan migrate:status` is identical before and after.
4. No web UI remains. routes/web.php stays as a file with no routes so bootstrap/app.php is untouched.
5. Starter-kit tests are deleted only as itemised in AC-4, each tied to a removed feature (TST5).
6. Packages are removed with `composer remove`. No retained package changes version.
7. Commit: `chore(contract): remove starter kit (ACC-C1)`. PR label: contract.
8. The one new test lives in a new folder, tests/Feature/Contract/. ARCHITECTURE.md section 5 gets one line for it (AC-7).

## Known traps

1. `php artisan route:list --except-vendor` hides Fortify and Livewire routes. It showed only home, dashboard, the settings redirect, the passkey endpoints and the two token routes. Capture the full list.
2. Unauthenticated non-JSON requests are redirected to `route('login')`. Without that route a 401 can become a 500. T0's JSON rendering for api/\* should prevent it, and AC-5 proves it. Do not edit bootstrap/app.php to make it pass. If it fails, send a CR.
3. T0 modified the starter tests and tests/Pest.php. Read what it changed in each file before deleting it, so nothing T0 needed is lost.
4. `composer remove` can move retained packages or drop a shared dependency Passport or spatie needs. Check with `composer show --direct` and `composer why`. If any retained package changes version, stop and send a CR.
5. Starter helper traits (app/Concerns/\* or similar) may serve both removed and retained code. Delete one only when Select-String shows no remaining user.
6. resources/views may hold views that retained code needs (mail, errors). Delete only views with no remaining reference, with grep evidence.
7. app/Providers/AppServiceProvider.php, bootstrap/app.php and routes/api.php may reference removed classes. Edit AppServiceProvider only to drop such references. If bootstrap/app.php or routes/api.php needs an edit, send a CR.
8. Delete configs only for removed packages (config/fortify.php, and config/livewire.php if it exists).
9. Never run migrate:fresh or other destructive database commands in this step (DBS6).
